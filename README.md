# Telegram-бот для анализа данных с помощью LLM-агента

Бот принимает датасет (CSV, TSV, XLSX, XLS), анализирует его с помощью LLM-агента, который пишет и выполняет Python-код, и возвращает текстовый отчёт с графиками.

## Как это работает
1. Пользователь отправляет боту файл с данными и, при желании, инструкцию в подписи к файлу.
2. Бот проверяет расширение файла, скачивает его во временную папку и запускает анализ в отдельном потоке.
3. Агент формирует системный промпт, краткую сводку по датасету (размер, колонки, типы, пропуски) и отправляет всё в LLM через OpenRouter.
4. LLM вызывает инструмент run_python — либо нативно, либо текстом в формате <tool_call><function=run_python><parameter=code>….
5. Код выполняется в дочернем процессе Python: в него передаются DATA_PATH, FIGURE_PATH, предзагружаются pandas, numpy, matplotlib, seaborn.
6. Если код создаёт matplotlib-фигуру, она сохраняется в файл; stdout/stderr и путь к графику возвращаются модели как результат шага.
7. Цикл повторяется до лимита шагов или до финального текстового отчёта; на последнем шаге инструмент принудительно отключается, чтобы модель выдала отчёт.
8. Бот отправляет отчёт частями (лимит Telegram) и прикрепляет все построенные графики, после чего удаляет временную папку.

## Установка и запуск
### 1. Установить зависимости
```bash
pip install requirements.txt
```
### 2. Получить API-ключи

Telegram Bot Token — создать бота у @BotFather и скопировать токен.

OpenRouter API Key — зарегистрироваться на [openrouter.ai](https://openrouter.ai), создать ключ в разделе API Keys.

### 3. Создать .env

Создайте файл .env в каталоге проекта и заполните его по образцу example.env:

```env
TELEGRAM_API_KEY=ваш_токен_телеграм_бота
OPENROUTER_API_KEY=ваш_ключ_openrouter
MAX_CONCURRENT=3
AGENT_MAX_STEPS=12
AGENT_PYTHON_TIMEOUT=180
```

### 4. Запустить бота

```bash
python bot.py
```
